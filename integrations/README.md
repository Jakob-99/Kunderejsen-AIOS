# Integrationer

Kode til at forbinde Figurio med eksterne platforme.

| Mappe | Formål |
|---|---|
| [`ga4/`](ga4/README.md) | Hente rapport-data fra Google Analytics 4 |
| [`instagram/`](instagram/README.md) | Publicere opslag på Instagram via Meta Graph API |

Alle secrets (tokens, service account-nøgler) holdes uden for git — se `.env.example` i hver mappe og repoets `.gitignore`. Følg setup-guiden i hver undermappes README, før scripterne kan køres.
