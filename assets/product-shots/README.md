# Product shots

Kuraterede AI-genererede (Artlist, style kit "Figurio Sage") visuals af figurerne — personfigurer, kæledyrsfigurer, forskellige vinkler/baggrunde. Bruges som stiliseret markedsføringsindhold og som referencebibliotek, så nye genereringer kan tage udgangspunkt i de her frem for at starte forfra hver gang.

**Vigtigt**: dette er *ikke* ægte produktfotos af faktisk printede figurer. Til produktsider/salgsmateriale hvor det skal fremstå som et løfte om det konkrete fysiske produkt, brug rigtige fotos i stedet.
