# Baggrunds-reference

`baggrund-reference.png` er beskåret direkte fra det originale personfigur-produktshot (ægte pixels, ikke syntetisk) — den standard sage-grønne studiobaggrund alle Figurio-produktshots skal bruge.

**Brug denne fil som eksplicit baggrunds-reference i alle fremtidige Artlist-genereringer af produktshots**, i stedet for kun at beskrive baggrunden med tekst. Send den som ekstra `input`-reference ved siden af figuren, og bed modellen om at kopiere baggrunden derfra uændret. Det giver langt mere konsistente resultater på tværs af figurer end en tekstbeskrivelse alene.
