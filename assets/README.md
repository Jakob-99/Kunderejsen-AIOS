# Assets

Rå og færdige filer til markedsføring og salgsmateriale for Figurio: logoer, produktfotos, genererede social- og annonce-billeder, video, mockups m.m.

## Struktur

Læg filer i undermapper efter type, fx:

- `logos/` — logo-filer (til lys/mørk baggrund, forskellige formater)
- `product-photos/` — produktbilleder
- `social/` — genererede/klargjorte opslag til sociale medier
- `ads/` — annoncebilleder og -videoer
- `misc/` — alt andet

Opret undermapper efter behov — der er ingen fast skabelon, læg filerne der hvor de naturligt hører til.
