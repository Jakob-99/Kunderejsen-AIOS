# Logos

Figurio-mærket: figuren i uniform med bjørneskindshue, hvid på salvie-grøn (`#3E5E3A`), eller salvie-grøn på hvid — se [`../../brand-guideline/brand-guideline.md`](../../brand-guideline/brand-guideline.md).

Varianter der bør ligge her:

- Mærke alene (rundt badge / figur uden ramme)
- Wordmark ("Figurio") alene
- Kombineret logo (mærke + wordmark)
- Lys og mørk version af hver
- Diverse filformater (SVG/PNG i høj opløsning, evt. favicon)
