# Logos

Figurio-mærket: figuren i uniform med bjørneskindshue, hvid på salvie-grøn (`#3E5E3A`), eller salvie-grøn på hvid — se [`../../brand-guideline/brand-guideline.md`](../../brand-guideline/brand-guideline.md).

## Filer

- `figurio-mark-cirkel.webp` — mærket alene, hvidt på rund salvie-grøn baggrund (badge/ikon-brug)
- `figurio-mark-fuld-figur.png` — mærket alene, fuld figur, salvie-grøn på transparent/hvid baggrund
- `figurio-logo-vandret.png` — kombineret logo (figur + "Figurio"-wordmark), vandret

Alle tre er de officielle logofiler.
